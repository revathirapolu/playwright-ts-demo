# Playwright + TypeScript UI Automation Framework

A clean, scalable UI automation framework built using Playwright Test Runner and TypeScript.  
Designed for maintainability, readability, and real-world testing workflows.

## Features
- Page Object Model (POM)
- Multi-browser testing (Chromium, Firefox, WebKit)
- Fixtures for authenticated sessions
- Utilities for test data and helpers
- CI-ready GitHub Actions workflow
- Screenshots, videos, and traces on failure

## Installation
```bash
npm install
npx playwright install
